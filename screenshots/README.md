# Screenshots

This directory contains visual evidence from the Wazuh SOC home lab.

The screenshots document the progression of the lab from endpoint monitoring and attack simulation through detection, alerting, automated response, and endpoint-level enforcement.

## Evidence Included

* Wazuh endpoint agents connected to the manager
* Simulated SSH authentication failures
* Custom SSH detection rule
* Wazuh detection alert
* Active Response configuration
* Ubuntu firewall block
* Windows Guest Account detection rule
* Windows Guest Account alert

The screenshots are provided as supporting evidence for the configurations and workflows described in the main project documentation.
